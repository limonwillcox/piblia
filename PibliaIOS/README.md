# Piblia iOS

Native SwiftUI app. The website phone shell is archived at `../archive/ios-web/`.

## Open in Xcode (Mac)

1. Open `Piblia.xcodeproj`
2. Pick an iPhone simulator
3. Run

If the project file misbehaves: **File → New → Project → iOS App → SwiftUI**, name it **Piblia**, then replace the generated sources with the files in `Piblia/`.

This will not build on Linux. No Simulator here.
