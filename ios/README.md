# iOS phone reader

Nested phone shell for Piblia. Desktop site stays at the repo root.

Open **`/ios/`** on a phone (or a narrow window). Shared texts, assets, and the KJV live one folder up so this copy does not duplicate the library.

| Path | What |
| --- | --- |
| `ios/index.html` | Phone home → reader |
| `ios/js/ios.js` | Top bar, tabs, focus, bookmarks |
| `ios/js/parallel.js` | L/R cycle, notes, landscape panes |
| `ios/js/kjv.js` | Loads KJV from `../Bibles/KJV/` |

After merge, the phone app is at `https://piblia.com/ios/`.
